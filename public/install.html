BRING YOUR OWN MACHINE

让你的机器，
成为声音的起点.

在电脑或服务器上运行执行器。机器主动连接你的频道，无需开放公网入站端口。

01

下载执行器

同一个安装包可以分发给多台机器。包含 Python 执行器、Docker 配置和完整使用说明，不包含真实密钥。

下载执行器 ZIP ↓SHA-256 校验值

02

为每台机器创建密钥

回到应用的「执行器」页面，点击「连接执行器」。为机器命名，并保存仅显示一次的密钥。每个密钥只处理所属用户的任务；不同机器使用不同密钥。

返回应用 →
03

使用 Docker 启动

在目标机器解压 ZIP，将 .env.example 复制为 .env。把 YOUTAST_TOKEN 的占位值替换成该机器的密钥，再在解压目录运行： 

docker compose up -d --build
docker compose logs -f

需要机器已安装并启动 Docker。环境文件包含私密凭据，请保存在可信机器上。

不使用 Docker 时，安装 Python 3.11+、FFmpeg，以及 Node.js 22+ 或 Deno 2.3+，再按包内 README 的 PowerShell / Linux 命令启动。

04

等待机器连接，开始转换

机器空闲时会逐步降低轮询频率，最多约 5 分钟发现新任务。机器必须能正常访问 YouTube；若站点要求人机验证，任务会显示失败原因，恢复网络后可在队列中重试。

机器连接后，为频道添加视频、playlist 或作者来源。音频生成后，在频道中复制私人 RSS 链接订阅。 

# 停止 Docker 执行器
docker compose down

停用某台机器时，也可以在应用中撤销它的密钥。

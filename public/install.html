03

选择一种方式启动

先在目标机器解压 ZIP，并在解压后的目录打开终端。以下方式任选一种；每台机器使用自己的密钥。

Docker

安装并启动 Docker 和 Docker Compose。将 .env.example 复制为 .env，编辑该文件：将 YOUTAST_URL 设置为你的应用地址，并将 YOUTAST_TOKEN 替换为这台机器的密钥。

docker compose up -d --build
docker compose logs -f

按 Ctrl+C 退出日志查看，容器继续运行。停止容器：docker compose down。

Windows：直接运行

安装 Python 3.11+、FFmpeg（包括 ffprobe），以及 Node.js 22+ 或 Deno 2.3+，并确保命令可在 PowerShell 中使用。在解压目录运行，将应用地址替换为自己的地址；输入密钥时不会显示字符：

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U -r requirements.txt
$env:YOUTAST_URL = 'https://your-worker.workers.dev'
$executorSecret = Read-Host 'Executor token' -AsSecureString
$env:YOUTAST_TOKEN = [System.Net.NetworkCredential]::new('', $executorSecret).Password
.\.venv\Scripts\python.exe agent.py

ZIP 也包含 Windows 后台启动脚本。要设置开机自动启动，请按包内 README 创建私密配置文件，然后以管理员身份在解压目录运行 .\scripts\windows-executor.ps1 -Boot。该任务以 SYSTEM 账户运行，依赖和配置文件须对该账户可访问；停止及日志查看方法见包内 README。

Linux / macOS：直接运行

安装 Python 3.11+、FFmpeg（包括 ffprobe），以及 Node.js 22+ 或 Deno 2.3+。在解压目录使用 Bash 运行以下命令，将应用地址替换为自己的地址：

python3 -m venv .venv
.venv/bin/python -m pip install -U -r requirements.txt
export YOUTAST_URL='https://your-worker.workers.dev'
read -rs -p 'Executor token: ' YOUTAST_TOKEN; export YOUTAST_TOKEN; echo
.venv/bin/python agent.py

直接运行时不会自动读取 .env；以上环境变量只在当前终端会话中有效。按 Ctrl+C 或关闭终端会停止执行器，重新启动时需要重新设置变量。长期后台运行可由机器管理员配置系统服务。环境文件和密钥请保存在可信机器上。

04

等待机器连接，开始转换

机器空闲时会逐步降低轮询频率，最多约 5 分钟发现新任务。机器必须能正常访问 YouTube；若站点要求人机验证，任务会显示失败原因，恢复网络后可在队列中重试。

在应用的「执行器」页面查看机器的报到状态。连接后，为频道添加视频、playlist 或作者来源。音频生成后，在频道中复制私人 RSS 链接订阅。

停用某台机器时，也可以在应用中撤销它的密钥。

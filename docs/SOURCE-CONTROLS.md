# 来源独立控制与弹窗关闭

## 每个来源独立取最新数量

在频道的“管理来源 → 设置”，或来源详情中的“来源设置”，可给每个来源设置最新展示数量，例如作者A取2条、作者B取3条。默认0/留空不单独限制；范围0–100。这里控制的是持续展示窗口，不是每次同步的批量数量。

先按每个来源筛选，再合并去重，最后应用频道总“最新N条”。因此来源2+3通常合计5条；视频同时属于两个来源时只展示一次，任意一个来源的窗口选中它即可。频道总量若设为4，最终仍最多4条。RSS、网页列表、缓存分类及待转换范围共用该窗口。

收窄范围保留已有音频并转为缓存；扩大范围可重新显示缓存，尚未生成的有效节目会重新排队。配额、保留期、过期/手动删除状态继续生效，并不保证始终有足数可播放音频。窗口只在已发现候选中选取，不自动补齐播放列表首次扫描范围以外的历史。

按原视频发布日期选最新；缺日期时按发现时间、作者列表前部/播放列表位置回退。排序和加入顺序仍是独立概念。节目可记录多个来源，迁移会回填已有可识别归属，后续扫描补充；更早期无可识别来源的记录继续受频道总量规则控制，不强行归到某个作者。

## 单来源暂停与同步

- “同步”只安排该来源，不把其他到期来源一起加入扫描队列。
- 暂停停止该来源的新扫描，并撤销其排队/运行中的扫描租约；已有节目、音频和来源数量窗口保留。已在进行的音频转换不因此强行中断。
- 恢复后安排该来源重新扫描；暂停时不能立即同步。
- 删除来源会解除该来源的独立窗口，既有节目按频道规则展示和转换，可能让此前窗口外的记录重新入队。只想停止更新并保留数量规则时使用暂停。

API：`POST /api/channels/:channelId/sources/:sourceId` 接受 `latest_limit`、`paused` 的部分更新；`POST .../:sourceId/sync` 单独同步。沿用用户、频道归属和Origin检查，不允许以这些入口修改其他字段。

新增 `0017_source_controls.sql`：来源数量/暂停状态、节目与来源多对多归属，以及新的共享节目窗口。迁移默认不限制、不暂停来源，保留旧频道行为；发布前后跨版本写入的已知归属也会在设置来源时补齐。需要已有window能力，播放列表还需discovery能力，无需新增执行器协议或重启已具备能力的执行器。

## 弹窗关闭方式

点击弹窗外的遮罩空白、X或按Esc均可关闭。弹窗内部留白仍属于弹窗，不会触发关闭；从弹窗内开始拖动到外部，也不会误关。

表单有未保存修改时，上述入口统一提示确认放弃；取消会保留输入。保存请求进行中禁用关闭，避免页面在结果返回前被误关。成功保存后正常关闭并刷新；弹窗代次检查防止旧异步回调关闭新弹窗。原有关闭时清除敏感字段的行为保留。

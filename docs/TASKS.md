# 处理任务与历史记录

2026-10-24。

## 展示规则

频道详情的“处理任务 N”统计待处理、处理中和真正失败的任务，与默认“当前任务”列表一致。全部完成且没有异常时为0。频道概览显示等待/处理中数量，并另列失败数量。

频道和全局任务页均可切换“当前任务 / 历史记录”，显示待处理、处理中、失败分项统计。已完成任务归入历史；来源暂停、退出最新N范围、用户删除音频、保留期到期清理及空间自动清理导致的任务停止显示“已停止”，归入历史，不提供任务重试按钮。需要重新生成音频时仍从节目入口操作；来源恢复和窗口扩大继续使用原有调度规则。

历史保留原记录。现有数据库将上述五类停止存为failed，本轮仅根据准确匹配的服务端原因映射display_status=stopped；未知错误仍显示失败，不按模糊文本吞掉异常。无数据库迁移、执行器或调度行为修改。

## API与链接

- `/api/jobs` 和 `/api/channels/:id/detail?tab=jobs` 默认 `tasks=current`，不再返回已完成任务。
- `tasks=history` 返回已完成及正常停止记录；非法分类返回400。
- `status` 保留存储值，`display_status` 为页面状态。`counts.jobs` 为当前任务总数，另返回history、queued、running、failed、active；active仍仅queued+running。计数不随搜索缩小，分页总数按分类与搜索计算。
- 分类、搜索及分页写入hash，例如 `#channel/:id/jobs/30?q=keyword&tasks=history`；切换分类回第一页，搜索/清除搜索保留分类；刷新、前进/后退保留链接状态。
- 旧dashboard兼容数组仍按原有规则返回，网页不使用该数组展示任务列表。
